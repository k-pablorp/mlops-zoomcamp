## Useful commands

Initate conda environment

```bash
    conda activate exp-tracking-env
```

Initiate mlflow in the background so terminal still usable
```bash
    mlflow ui --backend-store-uri sqlite:///mlflow.db &
```

Launch Jupyter Notebook
```bash
    jupyter notebook
```
